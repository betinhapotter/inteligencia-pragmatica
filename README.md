Inteligência, para o autor, é a capacidade de alcançar objetivos. Não é saber mais. É definir o que você quer, planejar como chegar e executar, ajustando conforme o mundo responde.

O livro inteiro responde a três perguntas, uma por parte. Cada pergunta tem uma ferramenta, e cada ferramenta tem uma sigla.

O pedido do autor é que você trate o livro como obra de consulta, daquelas que ficam na mesa. Esta página foi montada com essa lógica: resumo para reler, ferramentas para preencher e treino para fixar.
